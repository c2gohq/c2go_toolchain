# Contributing

C2Go is preparing its first coordinated public release. Code contributions are
not currently accepted for merge because the project has not yet published a
contributor agreement that preserves the copyright holder's ability to offer
commercial licenses.

Once public project channels are available, the following are welcome:

- reproducible bug reports without third-party confidential material;
- release reproducibility and platform-test findings;
- design discussion; and
- original documentation corrections.

Do not submit copied code, generated patches from a source you cannot license,
or confidential/proprietary material. A sign-off or hosting-platform term alone
must not be treated as permission for commercial relicensing.

The project will publish an updated contribution process before accepting code
pull requests.
