# Brand assets

`c2gohq-logo.png` is the provisional C2Go organization mark selected for the
project on 2026-07-27. It was generated with OpenAI's built-in image generation
tool from a project-owner-directed prompt describing a C-shaped transformation
arrow and was copied here without modification.

The image is 1254 x 1254 pixels, RGB PNG, and is intended to remain legible in
a circular GitHub organization avatar crop.

The logo is a branding asset, not software source code. It is excluded from the
repository's AGPL software grant as described in [../TRADEMARKS.md](../TRADEMARKS.md).
Before trademark registration or a major commercial launch, perform a
professional similarity and trademark clearance review.
