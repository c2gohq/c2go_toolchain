> **候选版本：**本版本用于评估和兼容性测试，尚未签名，也未达到生产可用状态。

C2Go Toolchain `v0.20260801.0-rc.2` 将无参数 managed region 确立为普通 C2Go
代码的默认写法，同时保留显式 world mask 供高级场景精细控制。

[English release notes](https://github.com/c2gohq/c2go_toolchain/blob/v0.20260801.0-rc.2/RELEASE_NOTES/v0.20260801.0-rc.2.md)

## 相比 v0.20260801.0-rc.1 的变化

- `#pragma c2go managed push` 现在默认启用 function、pointer、record 三项
  managed 行为，即 `C2GO_FUNC | C2GO_PTR | C2GO_RECORD`；这是大多数 managed
  region 的推荐写法。
- `managed(N)` 继续用于选择性控制。Mask 现在支持整数，以及经宏展开后由按位 OR
  和括号组成的表达式，例如 `managed(C2GO_PTR | C2GO_RECORD)`。
- 显式 mask 会校验是否落在受支持的 `0..7` 范围。空 `managed()`、未定义
  identifier、不支持的运算符以及不完整的 OR 表达式都会产生 pragma 诊断。
- 公开头文件、实现注释、回归测试和中英文文档现在对有效的 function bit 与默认
  写法保持一致。
- C2Go ABI epoch、Go 兼容范围、c2go-bind、c2go-libc 和 musl revision 均与
  rc.1 相同。

## 推荐的 region 语法

```c
#include <c2go.h>

#pragma c2go managed push
struct Node {
    struct Node *next;
    long value;
};
#pragma c2go pop
```

只有需要关闭某个 managed 默认项时，才使用显式符号 mask：

```c
#pragma c2go managed(C2GO_PTR | C2GO_RECORD) push
/* 本区域内只有声明的函数仍按 native import 处理 */
#pragma c2go pop
```

## 已知限制与许可证

- 仅支持 C，不支持 C++ 和 32 位目标。
- 仅支持 Go 1.25.x；Windows 的 POSIX 接口范围较小。
- C2Go 无法像 Go 编译器一样把发生逃逸的 C 栈局部变量提升到堆上；发布前必须把
  独立 `c2go-lto` 逃逸审计作为单独门禁。
- 接口和 ABI 细节仍处于 pre-1.0 阶段，后续可能修改。

`licenses/` 中的授权记录。商业协议不能重新许可 LLVM、musl 或其他第三方代码。
