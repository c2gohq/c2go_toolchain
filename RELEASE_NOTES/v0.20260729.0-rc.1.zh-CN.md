> **候选版本：**本版本用于评估、可复现性检查和兼容性测试，尚未达到生产可用
> 状态。

这是 C2Go Toolchain 的第一个协同发布候选版。它把编译器、绑定生成器、运行时
兼容层和嵌套的 musl fork 冻结成一个可复核快照。release tag 标识整套协同
快照；精确源码 revision 记录在 `toolchain.lock.json` 中，并在下表再次列出。

[English release notes](https://github.com/c2gohq/c2go_toolchain/blob/v0.20260729.0-rc.1/RELEASE_NOTES/v0.20260729.0-rc.1.md)

## 主要内容

- 提供协同的 C 到 Go 流水线：C2Go Clang 与 `c2go-lto` 输出 Go 兼容的
  Plan 9 汇编和 export manifest，`c2go-bind` 生成 Go 包，`c2go-libc` 提供
  与之匹配的运行时接口。
- 为 Linux amd64、Linux arm64、Windows amd64 和 macOS arm64 打包原生
  toolchain。
- 目标兼容范围为 Go 1.25.x 和 C2Go ABI epoch 1；release builder 使用
  Go 1.25.9。
- 包含当前 X86-64/AArch64 C2Go lowering、受支持的内联汇编处理、合成 libcall
  路由和 GC 安全修正。
- 删除已废弃的运行时 GC-mask lookup registry，同时保留承载含指针 C 全局变量
  所需的 Go-owned 聚合布局。
- 包含已跟踪的各目标 `c2go-libc` Go/汇编产物和外部原生调用 `dl` bridge。
- 提供递归完整对应源码包、每个文件的 SHA-256 sidecar 和汇总
  `SHA256SUMS`。

## 校验并试用

下载对应宿主的压缩包和 `SHA256SUMS`，解压前先校验。例如在 Linux 上：

```sh
sha256sum --check SHA256SUMS
tar -xzf c2go-toolchain-v0.20260729.0-rc.1-linux-amd64.tar.gz
export PATH="$PWD/c2go-toolchain-v0.20260729.0-rc.1-linux-amd64/bin:$PATH"

clang --version
c2go-lto --version
c2go-bind --version
```

压缩包内含匹配的 c2go-libc 源码/运行时包及适用的 release、许可和声明文档。
请把这些组件作为一个锁定整体使用。

## 发布验证

正式 tag 对应的 release workflow 会：

- 验证每个公开组件 tag 都精确解析到 `toolchain.lock.json` 记录的 commit；
- 在四个打包目标上原生构建 C2Go Clang、`c2go-lto` 和 `c2go-bind`；
- 在相应 builder 上运行仓库内的 `c2go-bind` 与 `c2go-libc` Go 测试；
- 在打包时核对工具版本和已锁定的 c2go-clang revision；
- 生成确定性二进制压缩包和递归完整源码包。

这些打包检查不会把项目自动变成经过生产认证的 C 实现，也不能替代组件仓库
完整的 LIT、clean checkout、来源审计或法律复核门禁。

## 已知限制

- 仅支持 C，不支持 C++。
- 仅支持 64 位 X86 和 AArch64；本版本只打包上述四种宿主。
- 仅支持 Go 1.25.x；该 ABI 版本线会主动拒绝 Go 1.26 及以后版本。
- `c2go-libc` 是供转换后程序使用的兼容层，不是宿主 libc 的直接替代品；
  Windows 的 POSIX 接口范围较小，也不支持 32 位目标。
- 接口、manifest 和 ABI 细节仍处于 pre-1.0 阶段，后续协同快照可能修改。
- 签名、Apple notarization、Windows Authenticode、SBOM 发布以及全仓来源/法律
  复核尚未完成。

反馈问题时请提供 release 版本、宿主 OS/架构、Go 版本、输入源码、完整命令行
和最小复现样例。
