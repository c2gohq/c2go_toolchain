> **Release candidate:** this build is for evaluation, reproducibility checks,
> and compatibility testing. It is unsigned and not production-ready.

C2Go Toolchain `v0.20260729.0-rc.3` corrects the platform-package layout from
rc.2. **Do not use the rc.2 binary SDK archives:** they contain development
source trees and omit the installed c2go-libc public-header tree. The complete
corresponding source remains available as a separate source asset.

[简体中文 release notes](https://github.com/c2gohq/c2go_toolchain/blob/v0.20260729.0-rc.3/RELEASE_NOTES/v0.20260729.0-rc.3.zh-CN.md)

## Highlights

- Ships each platform archive as a relocatable installed SDK with `bin/`,
  `include/`, `lib/`, `licenses/`, and release metadata only.
- Installs `c2go.h` and the complete tracked c2go-libc public C-header tree in
  top-level `include/`; source repositories, tests, and build scripts are no
  longer copied into binary SDKs.
- Makes packaged C2Go Clang discover the SDK `include/` directory and its Clang
  resource directory automatically in `-fc2go` mode. Normal Clang mode and
  `-nostdinc` controls retain their existing behavior.
- Fixes `fcntl.h` so its `off_t` declarations are self-contained.
- Extracts every native archive before upload, verifies the exact SDK layout,
  parses every supported public header without an extra `-I`, and executes a
  packaged C -> Plan 9 assembly -> generated Go package test.
- Publishes the complete corresponding source as a distinct `-source` asset,
  plus per-file SHA-256 sidecars and a combined `SHA256SUMS`.

## Installed SDK layout

```text
c2go-toolchain-v0.20260729.0-rc.3-<target>/
├── bin/                         clang, c2go-lto, c2go-bind
├── include/                     c2go.h and c2go-libc public C headers
├── lib/clang/<version>/         Clang runtime resources
├── licenses/                    component and third-party license records
├── README.md                    English installed-SDK quick start
├── README.zh-CN.md              Chinese installed-SDK quick start
├── BUILD-INFO.json
├── toolchain.lock.json
└── LICENSE, NOTICE, ...
```

The platform SDK intentionally does not bundle a precompiled Go archive or a
c2go-libc source checkout. Go archives depend on the exact Go version, build
settings, and dependency build IDs. Consumers should pin the matching module:

```sh
go get github.com/c2gohq/c2go_libc@v0.20260729.0-rc.3
```

## Verify and start

Download the archive for the host together with `SHA256SUMS` and verify it
before extraction. For example, on Linux amd64:

```sh
sha256sum --check SHA256SUMS
tar -xzf c2go-toolchain-v0.20260729.0-rc.3-linux-amd64.tar.gz
export C2GO_HOME="$PWD/c2go-toolchain-v0.20260729.0-rc.3-linux-amd64"
export PATH="$C2GO_HOME/bin:$PATH"

clang --version
c2go-lto --version
c2go-bind --version
```

Read the `README.md` or `README.zh-CN.md` inside the archive for the target
triple, matched c2go-libc module, and complete C-to-Go quick start.

## Release verification

The tagged workflow:

- validates remote component tags, locked revisions, recursive dependencies,
  and clean source snapshots;
- builds and tests C2Go Clang, `c2go-lto`, `c2go-bind`, and c2go-libc natively
  on Linux amd64/arm64, Windows amd64, and macOS arm64;
- creates deterministic platform SDKs and a recursively complete source bundle;
- rejects source-tree payloads, missing or unexpected installed headers,
  missing license records, and incorrect build metadata in platform archives;
- extracts each archive and runs the public-header and complete packaged-tool
  smoke tests before it can be uploaded.

These checks do not make the candidate a production-certified C
implementation and do not replace complete provenance or legal review.

## Known limitations

- C only; C++ is not supported.
- 64-bit X86 and AArch64 only; this release packages the four hosts above.
- Go 1.25.x only. Go 1.26 and later are outside this ABI line.
- `c2go-libc` is a compatibility layer for translated programs, not a drop-in
  host libc. Windows has a smaller POSIX surface, and 32-bit targets are not
  supported.
- Interfaces, manifests, and ABI details remain pre-1.0 and may change.
- Signing, Apple notarization, Windows Authenticode, SBOM publication, and
  repository-wide provenance/legal review are not complete.

Please report results with the release version, host OS/architecture, Go
version, input source, full command line, and a minimal reproducer.
